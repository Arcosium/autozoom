# AutoZoom — 회의 참석부터 근거 기반 요약까지

Zoom 회의·웨비나, 일반 영상, 직접 녹음 파일을 전사하고 액션 아이템·결정 사항·미해결 주제로 정리하는 로컬 AI 회의 시스템이다. 요약은 원문을 근거로 하며, 사용자는 전사 기록에 질문하고 근거 시각을 확인할 수 있다.

## 평가자용 요약

| 평가 관점 | 구현 |
|---|---|
| 입력 경로 | Zoom 예약·즉시 참석, 영상 URL, 대용량 파일 분할 업로드, 브라우저·앱 녹음 |
| 실시간 처리 | 방송 시작 감지, 오디오 캡처, 실시간 전사, 중지·재시작 복구 |
| 근거 기반 AI | 원문에 없는 사실 생성 금지, 불명확 표시, 질의응답의 시각 근거 |
| 지식 연결 | 요약을 ArcAI.ve Coresight 카드로 보내 재색인 |
| 제품 표면 | FastAPI 웹, 계정 승인, Android 앱, 예약 스케줄러 |

## 흐름

```text
URL·녹음·파일
  → 참석/수집
  → 오디오 정규화·청크 분할
  → STT
  → 원문 기반 요약·질의응답
  → Coresight 재색인
```

## 구조

| 경로 | 역할 |
|---|---|
| `app/server.py` | 인증, 잡 생성, 분할 업로드, 상세·관리 API |
| `app/jobs.py` | SQLite 잡 상태머신과 예약 스케줄러 |
| `app/zoom_bot.py` | Playwright + Xvfb를 이용한 회의 참석·종료 감지 |
| `app/live_stt.py`, `app/stt.py` | 실시간·파일 전사 |
| `app/summarize.py` | 로컬 LLM 요약, 제목 생성, 원문 질의응답 |
| `app/coresight.py` | 회의 요약을 지식 카드로 변환·재색인 |
| `mobile/` | Android 동반자 앱 |
| `tests/` | 인증·링크·미디어·녹음 회귀 테스트 |
